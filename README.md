# 🤖 کنترل سیستم شخصی با بات تلگرام

> از هر جای دنیا، با تلگرامِ گوشی‌ات، لپ‌تاپ/کامپیوتر خودت را کنترل کن:
> اسکرین‌شات بگیر، فایل بفرست و بگیر، دستور اجرا کن — و حتی با هوش مصنوعی (opencode) **به زبان آدمیزاد** حرف بزن و بگو «فایل منیجر را در پوشه عکس‌ها باز کن» تا انجامش دهد!

- ⭐ **بدون سرور، بدون هزینه، بدون VPN گران** — همه چیز روی سیستم خودت اجرا می‌شود
- 🔐 فقط **خودت** می‌توانی به بات فرمان بدهی (شناسایی با Chat ID)
- 🧠 متصل به **opencode** برای دستورات فارسی و پیچیده

## 🧰 پیش‌نیازها

- یک کامپیوتر/لپ‌تاپ **ویندوزی** (۱۰ یا ۱۱) که روشن و آنلاین است
- حساب **تلگرام** روی گوشی
- **اینترنت** روی کامپیوتر
- اگر در ایران هستی: یک **پروکسی/VPN** فعال روی کامپیوتر (چون تلگرام فیلتر است — بات هم بهش نیاز دارد)

بقیه همه رایگان و نصب‌شدنی است. برو مرحله به مرحله 👇

## مرحله ۱: نصب پایتون

1. برو به: **https://www.python.org/downloads/**
2. دکمه زرد بزرگ **Download Python 3.x** را بزن
3. فایل دانلود‌شده را اجرا کن
4. ⚠️ **مهم‌ترین لحظه این مرحله:** در صفحه اول نصب، **تیک گزینه `Add python.exe to PATH` را حتماً بزن!** (اگر نزنی، هیچ‌چیز کار نمی‌کند)
5. **Install Now** را بزن و صبر کن تمام شود
6. **تست:** منوی استارت را باز کن، تایپ کن `PowerShell` و Enter بزن. حالا تایپ کن:
   ```
   python --version
   ```
   اگر نوشت مثلاً `Python 3.13.5` → عالی، رد شو به مرحله بعد ✅
   اگر ارور داد → یعنی تیک مرحله ۴ را نزدی. ویندوز را ری‌استارت کن؛ اگر باز هم نشد، پایتون را حذف و از اول با تیک نصب کن.

## مرحله ۲: ساخت ربات با BotFather

**BotFather** ربات رسمی تلگرام است که بات‌های جدید می‌سازد. مثل ثبت‌نام اسم است.

1. تلگرام گوشی‌ات را باز کن
2. بالای صفحه، آیکون **ذره‌بین 🔍** را بزن
3. تایپ کن: `@BotFather` و روی نتیجه با **تیک آبی ✅** بزن
4. دکمه **Start** را بزن
5. دستور `/newbot` را بفرست (بفرست یعنی تایپ و دکمه Send)
6. BotFather می‌پرسد: **نام ربات چی باشد؟** → هر اسمی دوست داری بنویس. مثلاً: `کنترل لپ تاپ امین` (این اسم نمایشی است، هرچه می‌خواهی)
7. حالا می‌پرسد: **username چی باشد؟** → این باید:
   - به **`bot`** ختم شود (اجباری!)
   - یکتا باشد. مثلاً: `amin_laptop_bot` — اگر گفت قبلاً گرفته شده، یک عدد اضافه کن: `amin_laptop_777_bot`
8. 🎉 تمام! BotFather یک پیام می‌دهد که وسطش این متن هست:

```
Use this token to access the HTTP API:
<TOKEN-EXAMPLE-HERE>
```

9. **این خط طولانی، «توکن» بات توست.** مثل رمز عبور بات است!
10. آن را **کپی کن** و در یک جای امن بگذار (مثلاً Notepad). در مرحله ۶ لازمش داری.

> 💡 هر وقت خواستی توکن جدید بگیری: در BotFather دستور `/mybots` → باتت را انتخاب کن → **API Token** → **Revoke current token**.

## مرحله ۳: پیدا کردن Chat ID خودت

**Chat ID** شماره یکتای حساب تلگرام توست. بات با این شماره می‌فهمد فقط تو مالکی و غریبه‌ها حق فرمان ندارند.

### روش ساده (پیشنهادی):
1. در تلگرام، ذره‌بین 🔍 را بزن و تایپ کن: `@userinfobot`
2. **Start** بزن
3. فوراً یک پیام می‌دهد که اولش نوشته:
   ```
   Id: 123456789
   ```
4. **این عدد، Chat ID توست!** کپی کن و کنار توکنت در Notepad بگذار.

### روش دوم (اگر خواستی خودت تست کنی):
1. در BotFather پیامت را نیمه‌کاره رها کن! اول این کار را بکن: باتت را در تلگرام پیدا کن (با usernameای که مرحله ۲ ساختی) و **Start** بزن و یک پیام دلخواه بفرست: `salam`
2. حالا این لینک را در **مرورگر کروم کامپیوتر** باز کن (توکن خودت را جایگزین کن):
   ```
   https://api.telegram.org/bot<YOUR-TOKEN>/getUpdates/getUpdates
   ```
   (دقت کن قبل از توکن کلمه `bot` آمده و بعدش `/getUpdates`)
3. در جوابی که می‌آید دنبال این بگردی: `"chat":{"id":123456789,...`
4. آن عدد بعد از `id:` همان Chat ID توست.

## مرحله ۴: نصب opencode (هوش مصنوعی)

**opencode** مغز بات است. با این، به‌جای دستورات آماده، به بات فارسی می‌گویی «فلان کار را بکن» و او روی کامپیوترت انجامش می‌دهد.

> ⚠️ اگر فقط دستورات ساده (`/shot`، `/file` و…) را می‌خواهی و AI نمی‌خواهی، این مرحله را رد کن و در `config.json` مربوط به opencode را دست نزن — بات برای دستورات ساده به AI نیازی ندارد.

1. **Node.js** را نصب کن (opencode به آن نیاز دارد):
   - برو به: **https://nodejs.org/**
   - نسخه **LTS** را دانلود و نصب کن (Next → Next → Finish)
   - تست در PowerShell: `node --version` → باید مثلاً بنویسد `v22.x.x`
2. **opencode** را نصب کن — در PowerShell تایپ کن:
   ```
   npm install -g opencode-ai
   ```
   و صبر کن تمام شود.
3. **تست:**
   ```
   opencode --version
   ```
   باید شماره نسخه بنویسد (مثلاً `1.18.30`) ✅
4. **اتصال به یک مدل هوش مصنوعی:** opencode را یک بار در PowerShell اجرا کن:
   ```
   opencode
   ```
   - صفحه‌ای باز می‌شود؛ مدل/سرویس‌دهنده را انتخاب و **لاگین/کلید** بده. (می‌توانی سرویس رایگان انتخاب کنی یا کلید هر سرویسی که داری.)
   - بعد از اتمام، با `exit` یا بستن پنجره خارج شو.
5. **تست نهایی AI:**
   ```
   opencode run "فقط بنویس: سلام"
   ```
   اگر جواب داد → مغز بات آماده است 🧠

## مرحله ۶: پر کردن config.json

1. داخل پوشه پروژه، فایل **`config.example.json`** را با **Notepad** باز کن
   (راست‌کلیک → Open with → Notepad)
2. **Save As** بزن و اسمش را بگذار **`config.json`** (یعنی نسخه جدید بساز؛ فایل example را دست نزن)
3. حالا فیلدها را پر کن:

| فیلد | چی بنویس | از کجا آورده‌ای؟ |
|---|---|---|
| `token` | توکن BotFather از مرحله ۲ | مرحله ۲ |
| `owner_id` | عدد Chat ID تو (بدون کوتیشن) | مرحله ۳ |
| `downloads_dir` | مسیر پوشه دریافت فایل‌ها. دقت کن `YOUR-USERNAME` را با اسم کاربری ویندوز خودت عوض کن | — |
| `max_upload_mb` | حداکثر حجم ارسال فایل (پیش‌فرض ۵۰ بماند) | — |
| `proxy` | اگر در ایرانی: آدرس پروکسی سیستم، مثلاً `http://127.0.0.1:8080` یا `http://10.0.0.1:8080` (پیدا کردنش پایین همین جدول 👇). غیر ایرانی: خالی بگذار `""` | — |
| `opencode_exe` | اگر مرحله ۴ را نصب کردی: همان پیش‌فرض `opencode` بماند | — |
| `opencode_server` | `http://127.0.0.1:4097` (دست نزن) | — |
| `opencode_server_user` | `opencode` (دست نزن) | — |
| `opencode_server_pass` | یک رمز دلخواه بنویس، مثلاً `my-secret-123` | خودت اختراع کن |
| `opencode_model` | اسم مدل، مثلاً `openai/gpt-4o-mini` یا هر مدلی که در مرحله ۴ انتخاب کردی | مرحله ۴ |
| `opencode_workspace` | پوشه پیش‌فرض کار AI، مثلاً `C:\Users\ali` | — |

### 🔎 پیدا کردن آدرس پروکسی (فقط ایرانی‌ها):
پروکسی/VPN که تلگرام با آن کار می‌کند معمولاً یک برنامه است (مانند V2rayN، Hiddify، Nekoray و…). آدرسش:
1. برنامه VPN/پروکسی‌ات را باز کن — دنبال عددی به شکل `127.0.0.1:xxxxx` یا `پورت: 2080/10808/7890` بگرد (در تنظیماتش هست)
2. یا در ویندوز: **Settings → Network & Internet → Proxy** — اگر **Manual proxy** روشن است، همان آدرس را بنویس (با `http://` اولش)
3. در `config.json` به این شکل بنویس: `"proxy": "http://127.0.0.1:10809"`
4. در `config.json` به این شکل بنویس: `"proxy": "http://127.0.0.1:10809"`
4. راه مطمئن‌تر: از PowerShell دستور زیر را بزن و خروجی ProxyServer را بردار:
   ```powershell
   Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings" | Select ProxyEnable, ProxyServer
   ```

4. فایل را **Save** کن.

## مرحله ۸: اجرای خودکار با روشن شدن ویندوز

می‌خواهی هر بار ویندوز بالا آمد، بات خودش روشن شود؟

**راه آسان:** در PowerShell این را اجرا کن (داخل پوشه پروژه):
```powershell
python install_autostart.py
```
اگر پیام SUCCESS داد → تمام! از این به بعد با هر ورود به ویندوز، بات خودکار ران می‌شود.

**راه دستی (اگر اسکریپت نشد):**
1. کلیدهای `Win + R` را بزن، تایپ کن: `shell:startup` و Enter
2. پوشه‌ای باز می‌شود → راست‌کلیک → **New → Shortcut**
3. در مسیر، برو/برگرد به فایل `start.bat` داخل پوشه پروژه و انتخابش کن
4. اسمش را بگذار `RemoteAssistantBot` → Finish
5. تمام! با هر بوت ویندوز، بات بالا می‌آید.

> 💡 برای حذف autostart: همان پوشه `shell:startup` را باز کن و میان‌بر را پاک کن.

## 🛠 حل مشکلات (باگ‌های رایج)

### ❌ «python is not recognized»
تیک `Add to PATH` را موقع نصب پایتون نزدی. پایتون را حذف کن، دوباره نصب کن و حتماً تیک را بزن. بعد ویندوز را ری‌استارت کن.

### ❌ «ModuleNotFoundError: No module named 'psutil'»
کتابخانه‌ها نصب نیستند. در PowerShell:
```
pip install requests psutil mss
```

### ❌ بات بالا می‌آید ولی پیام‌ها جواب نمی‌دهد / «Connection refused»
**تلگرام از کامپیوترت در دسترس نیست.** چون بات روی کامپیوتر اجرا می‌شود، تلگرامِ کامپیوتر باید باز شود:
- اگر ایرانی هستی: برنامه VPN/پروکسی روی **همان کامپیوتر** روشن باشد
- آدرس پروکسی را درست در `config.json` گذاشته باشی (بخش مرحله ۶)

### ❌ «401 Unauthorized» از تلگرام
توکن غلط است. دوباره از BotFather کپی کن (دقت کن دو طرفش فاصله/فیلتر اضافه نماند).

### ❌ بات می‌گوید «⛔ تو مالک این بات نیستی»
`owner_id` در config.json با Chat ID واقعی‌ات فرق دارد. با @userinfobot چک کن.

### ❌ AI جواب نمی‌دهد: «سرور opencode بالا نیامد»
1. `opencode --version` در PowerShell کار می‌کند؟ اگر نه، مرحله ۴ را تکرار کن
2. مدل را در opencode لاگین/تنظیم کرده‌ای؟ یک بار `opencode` را دستی اجرا کن و مدل را وصل کن
3. `opencode_server_pass` در config.json با رمزی که سرور با آن بالا می‌آید یکی است؟ (بات خودش سرور را با همان رمز بالا می‌آورد — پس فقط مطمئن شو رمز دلخواه گذاشته‌ای)

### ❌ بات می‌گوید «اعتبار این مدل تمام شد»
سرویس AI رایگان تو موجودی‌اش تمام شده. در `config.json` فیلد `opencode_model` را عوض کن:
- `opencode/big-pickle` → مدل رایگان خود opencode (سریع)
- هر مدل دیگری که در حساب opencode‌ات اعتبار دارد
بعد `start.bat` را دوباره اجرا کن.

### ❌ پیام «409 Conflict» در کنسول
یعنی **دو نمونه** بات همزمان اجراست (مثلاً دوبار `start.bat` زده‌ای). نسخه جدید خودش جلوی این را می‌گیرد — پنجره اضافی را ببند.

### ❌ اسکرین‌شات سیاه/خالی می‌آید
اگر بعد از Lock شدن ویندوز یا Remote Desktop بگیری، صفحه واقعی در دسترس نیست. ویندوز را Unlock کن.

### ❌ فایل بزرگ ارسال نمی‌شود
تلگرام برای بات‌ها سقف ۵۰MB دارد. `max_upload_mb` را بیشتر کنی هم فایده ندارد (محدودیت خود تلگرام است).

### ❌ بعد از تغییر config.json چیزی عوض نشد
بات را ببند (پنجره سیاه) و دوباره `start.bat` را اجرا کن — تنظیمات فقط موقع شروع خوانده می‌شود.

### ❌ دو بار بات را اجرا کردم و رفتار عجیب شد
فقط یک نمونه از بات باید اجرا باشد! پنجره‌های اضافی را ببند، در Task Manager دنبال pythonهای اضافی بگرد و ببند.

## 🔐 امنیت — حتماً بخوانید

این بات یک **دربِ کنترل از راه دور** روی کامپیوترت است. این قوانین را جدی بگیر:

1. **توکن بات = کلید خانه‌ات.** هر کسی توکن را داشته باشد باتت را کنترل می‌کند!
   - توکن را هرگز در کد/گیت‌هاب/گروه نفرست
   - `config.json` را **هرگز commit و آپلود نکن** (در .gitignore هست ولی تو هم مواظب باش)
   - اگر شک کردی لو رفته: BotFather → `/mybots` → API Token → **Revoke** → توکن جدید در config.json
2. **Chat ID تنها سد امنیتی است** — بات پیام‌های غریبه را رد می‌کند، ولی پسورد ویندوزت هم قوی باشد.
3. **دستورات AI را با احتیاط بده** — مدل می‌تواند فایل حذف/جابه‌جا کند. برای پوشه‌های مهم نسخه پشتیبان داشته باش. (دستورات مخرب سطح سیستم مثل shutdown در کد فیلتر شده‌اند، ولی حذف فایل شخصی از سوی مدل را هیچ باتی نمی‌تواند برگرداند!)
4. **این پروژه شخصی است** — روی کامپیوتر کسی جز خودت اجرا نگیر.
5. `bot.log` همه مکالمات را ثبت می‌کند — گاهی برای دیباگ مفید است، ولی حاوی محتوای خصوصی توست؛ آپلودش نکن.

## ❓ سوالات پرتکرار

**آیا کامپیوتر باید همیشه روشن باشد؟**
بله. بات روی کامپیوتر تو زندگی می‌کند. خاموش شود، بات هم خواب است.

**از گوشی می‌توانم نصبش کنم؟**
نصب روی ویندوز است؛ اما **کنترل** از تلگرام گوشی انجام می‌شود. یعنی کامپیوتر روشن خانه + تو بیرون با گوشی = کنترل کامل.

**دیتا/پول مصرف می‌کند؟**
پروژه و ابزارها رایگان‌اند. اگر مدل AI انتخابی‌ات پولی باشد، هزینه‌اش مال همان سرویس است — مدل رایگان انتخاب کن، صفر می‌شود.

**آیا بات من را زیر نظر دارد؟**
`bot.log` روی همین کامپیوتر ذخیره می‌شود و هیچ‌جا فرستاده نمی‌شود. تنها چیزی که به بیرون می‌رود، پیام‌های تو به API تلگرام و درخواست‌های AI به سرویس مدلی است که خودت انتخاب کرده‌ای.

**چطور بات را کلاً حذف کنم؟**
1. پنجره بات را ببند
2. میان‌بر `shell:startup` را پاک کن
3. پوشه پروژه را حذف کن
4. در BotFather: `/mybots` → باتت → **Delete bot**
